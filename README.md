# Aryan Mane — Resume

Standalone resume viewer and download page for [resume.aryanmane.xyz](https://resume.aryanmane.xyz).

## Features
- Embedded interactive PDF viewer
- One-click PDF download button
- Direct link back to [aryanmane.xyz](https://aryanmane.xyz)
- Gruvbox dark theme matching the main portfolio
- Responsive mobile fallback
- Hosted on Cloudflare Pages

## Deployment
Deploy directly to Cloudflare Pages using Wrangler:
```bash
wrangler pages deploy . --project-name=resume
```
